# GitHub repository settings for Eventide

Set these by hand under the repository's **Settings** (they can't be set from a commit).

## About → Description

Eventide: a Minecraft launcher for Windows with its own Fabric mod (HUD, PvP tools, knives, living skies, Name Protect). Formerly 3vhy client.

## About → Topics

minecraft, minecraft-launcher, fabric-mod, minecraft-mod, tauri, vue, windows, modrinth, pvp, hud

## Settings → General → Social preview

Upload `assets/brand/eventide-social-preview.png` (1280 × 640, the lockup on #0C0914).

## Repository name

Rename the repository (Settings → General → Repository name), for example to `eventide`. GitHub
redirects the old URL. After that, the hard-coded `github.com/3vhy/3vhy-client` URLs in the code,
README, website and mod metadata are updated to the new name.
